# 系统配色、字体搭配与颜色卡验收

日期：2026-10-22。新增系统自带配色与字体选择，默认浅色「暖白墨黑＋宋黑搭配」。已有有效偏好继续使用，缺失或无效的配色／字体修复为默认值。

## 功能

- 8 套浅色：暖白墨黑、鼠尾草绿、燕麦奶咖、暖陶杏橙、雾蓝石灰、莲雾浅粉、淡紫云雾、青柠橄榄。
- 4 套暗色：午夜石墨、深夜松绿、深海雾蓝、可可炭棕。
- 浅色、深色、跟随系统三种模式。跟随系统可分别保存浅色和暗色配色，按系统外观切换。
- 颜色卡同时展示背景、侧栏、主要文字、辅助文字、强调色；选中项有勾选标记，支持原生单选键盘操作。
- 效果预览包含品牌、页面标题、正文、营养数值与主要按钮。未保存的修改只影响预览；保存才应用全局。桌面侧面预览可折叠，窄屏默认收起，避免遮住颜色卡。
- 4 套字体搭配：宋黑搭配、清晰黑体、书卷宋体、温柔文楷。标题、正文、界面控件和营养数值使用独立语义角色。宋黑搭配的宋体标题采用真实 700 粗体，正文、控件与数值采用黑体。
- 对话显示、推荐回复仍放在同一设置分类的独立标签页，配色选择不会覆盖这些偏好。

## 资源与统一应用

`appearance-presets.js` 是应用与预览的同一目录源；`appearance.js` 统一解析偏好、系统模式与 CSS 语义变量，处理跨页面存储事件。主要按钮文字从画布颜色改用独立 `--color-on-accent`，浅色和暗色均有明确前景色。

Noto Sans SC、Noto Serif SC 和 LXGW WenKai TC 随静态资源提供，原字体许可证、来源和 SHA-256 见 `static/fonts/README.md`。保留上游完整字符集，无运行时第三方字体请求。最终 WOFF2 已读取验证：Sans 30,890 字符、wght 100–900；Serif 30,928 字符、wght 200–900；WenKai TC 22,401 字符、Regular。三项本地 HTTP 请求均 200，文件头均为 wOF2。

验收时发现 Google Fonts 接口对工具客户端返回的是常规静态字重，不能仅通过 CSS 700 声称存在粗体。因此最终 Noto 字体直接使用官方仓库的完整可变字体，并再次校验字重轴；同时提高标题规则的匹配优先级，避免设置页原有 600 字重覆盖选中的 700。
