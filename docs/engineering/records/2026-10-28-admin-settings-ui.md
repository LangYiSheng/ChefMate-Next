# 管理平台、个人设置与会员模板整理

基线 `96d1390`，分支 `codex/accounts-admin-docker`。依据2026-10-28的9条浏览器批注整理；未调整版本与发布日志。

## 对应改动

- 管理平台采用设置页同一套字号、内容轴、分组间距和surface色阶，标题与滚动内容分离；成本、数据、用户和审计表格通过柔和表面区分，不用细描边围住大块内容。清理旧“模型页内嵌整套设置”的13条遗留样式，避免重新引入网格与内边距冲突。
- 单模型卡片最大560px，双卡区域最大1080px，多卡自适应；提供商、连接状态、协议与密钥、三项价格和动作分别集中，去掉卡片与端点描边。模型编辑按连接、能力、价格分组。
- 管理入口与分类内容使用原有motion token的淡入/轻位移动画，保留减少动态效果的媒体规则。
- 资料与安全页面移除旧三列表单类，使用设置的标准Field组行，身份信息独立表面；密码字段纵向排列，提交动作与表单对齐。各设置分类按任务选择阅读宽度，宽屏组件网格自适应，能力列表可展开其余项目。
- 个人额度页和账号卡片只显示比例、占用状态与恢复时间；各资金来源与窗口分别计算，当前会员容量不重复相加两个重叠窗口。无上限显示∞/不限，细小使用保留小于0.1%等提示。管理员继续查看真实金额，后台扣减、历史金额和预留逻辑不变。
- 会员模板可新增、编辑、删除、套用并继续修改本次参数；模板保存在account_settings，具有管理员/同源校验及CAS保护。套用只填草稿，不自动授予，也不追改旧会员。
