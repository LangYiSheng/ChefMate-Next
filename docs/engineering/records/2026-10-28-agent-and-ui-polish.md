## 第一轮：弹窗居中与测试资源清理

称呼弹窗没有水平居中。根因是个人账号页的直属子元素规则统一设置 `margin-inline:0`，误伤原生 `dialog` 的自动边距；不是模型或浏览器缩放造成的问题。现在该布局规则排除弹窗，共用 `.session-dialog` 明确设置 `inset:0; margin:auto`。

真实浏览器基线：2216×1244，动画结束后弹窗左缘为 0，水平中心偏移 -898px。补丁后水平偏移 0、垂直偏移小于 0.001px；390×844 亦保持居中、没有页面横向溢出。生产构建与类型检查通过。此次只改布局样式，未重跑与该修补无关的财务或智能体测试。

清理了 19 个已停止的 ChefMate 历史测试容器、6 个没有连接容器的旧测试网络和 12 个不再被容器引用的旧测试镜像。保留当前日常服务、一个隔离测试数据库、原有 `ChefMate_Test`，以及全部数据卷和备份；其他项目的容器与镜像未动。当前日常镜像保留为回退版本。

为避免并行开发中的未完成补丁进入日常镜像，后续构建从指定提交的 Git 归档获取源代码，而不是直接打包正在修改的工作区。每轮部署后的提交标识、就绪状态与数据指纹另行核对。
