# 会员额度、多模型与账号设置迭代

基线 `cbc19d4`，分支 `codex/accounts-admin-docker`。本轮没有调整版本或发布日志。

## 行为与存储

- 默认 ¥5 永久基础额度，管理员可追加永久充值、有效期与周/5小时限额独立的会员。用户明确选择首次使用起算的固定窗口；按会员、基础、充值顺序分摊，资金来源与窗口持久化。旧金额与历史占用迁入基础，避免升级重复发钱。
- 预留以每次模型调用为分摊单位，跨窗口结算、未知 usage、服务恢复和管理员核对保留原来源。会员与充值授予携带幂等 ID，网络重试不会重复发放。
- 管理员保存多个含独立提供商、协议、端点、模型、密钥与单价的连接。只能启用一个；测试备用模型使用其自身价格。连接、价格与测试状态都有版本检查，密钥不回显。
- 管理平台平铺模型、运行、上下文、组件；数据计数与服务状态合并。操作记录加入分页、关键词与人员/操作/北京时间日期筛选。
- 左下角账号卡片集中入口与退出。设置顶部为个人资料、我的额度、账号安全；个人偏好集中厨房与手写偏好，长期记忆显示助手总结。
- 厨房偏好与长期记忆统一授权，账号与记忆投影原子保存。称呼独立传给模型；关闭偏好开关时不附带其余档案。旧禁用状态与曾清空的投影保守迁移，修改称呼不会恢复已清空内容。

## 验证范围

资金、模型与偏好使用独立 SQLite 兼容夹具和真实 PostgreSQL 随机 schema 验证；模型工具测试使用模拟 SDK，不向外部发送真实用户内容。预览使用独立 `membership_preview` 命名空间及合成账号。

- 会员金额专项 42 项、模型 22 项、审计 30 项、模型实际挂载与账本迁移 11 项通过；记忆工具核心回归 22 项、新增授权撤回 HTTP 专项 12 项通过。
- 前端 42 文件、357 测试通过，生产构建通过。桌面及 390×844 手机浏览器检查账号卡片、个人资料与偏好、额度、管理分类和操作记录；浏览器没有警告或错误。
- Docker 独立项目 `chefmate-membership-qa` 在 18878 首次启动，真实导入 358 道公共菜谱，验证 ¥5 基础 + ¥10 充值 + 当前 ¥2 会员、幂等发放、唯一模型切换、审计和统一偏好，未调用供应商。重启后会员、余额和激活模型一致。
- Docker 中额度弹窗桌面宽 1000px、模型编辑宽 780px；390px 视口下均为354px、字段纵向且无横向溢出。检查仅展开和取消表单，没有发放或模型外发。
- 日常服务更新前已成组备份双库与文件，另保存60张个人业务表的内容指纹、5个账号和2条中央用量原记录；备份清单校验与升级后结果在最终完成时追加。

完整回归与日常 Docker 切换结果在完成后追加。偏好关闭的检查覆盖无厨房档案的手写偏好/助手总结、工具返回历史条目和重复模型轮；已经准入的调用及其 SDK 内部重试保留当次授权语义。
