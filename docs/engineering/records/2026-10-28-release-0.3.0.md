## 发布范围与来源

应用从 0.2.2 更新到 **0.3.0**。本次实现来源为 `codex/accounts-admin-docker`，截至 `4e55a48ea0952d4870541cf41a9f1472a4a13cad`；设置中的[版本更新日志](../../../apps/chefmate-playground/releases.json)保留这一来源及分支内其他 24 次提交。0.2.2、0.2.1、0.2.0 的内容、日期和提交来源原样保留。

本版新增账号注册登录、欢迎引导、按用户隔离的厨房资料、金额计价与固定窗口会员、管理员平台、多模型连接及独立单价。用户额度采用百分比展示，管理端保留金额核对。Docker 启动应用和两个 PostgreSQL，随仓库提供 358 道基础菜谱，并提供旧 SQLite 迁移及备份恢复流程。离线清洗和 USDA 原始库不随在线业务库迁移；充值额度由管理员发放，未接入在线支付。
