# 称呼编辑与设置侧目录

本轮根据个人资料和版本日志的两条浏览器批注调整界面，保留现有统一字号、阅读宽度和进入动画。版本号与发布日志不变。

## 界面变化

- 个人资料页把称呼摘要与小编辑按钮放到“读取最新”左侧，移除下方独立的大表单。点击打开紧凑弹窗，保存仍使用原账号资料接口，并刷新账号信息。
- 取消明确放弃本次修改；关闭弹窗可保留草稿，再次打开继续。未保存草稿离开页面、读取最新与保存中的保护仍生效。保存和刷新出错分别反馈，避免把已经保存的称呼冒充没有保存。
- 设置目录只在正文右侧有足够空间时显示；空间不足或手机端隐藏，不转移到顶部，也不占用正文的列宽。所有有目录的设置页遵循相同规则。
- 更新日志目录只标版本号；版本副标题、摘要和各分节继续保留在正文，历史内容与提交来源不变。
