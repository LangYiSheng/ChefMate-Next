| 反馈 | 实现 |

| 1：完整步骤过于松散、操作重复 | 改为紧凑编号列表，突出当前步骤；只有选中行显示完成与适用的计时操作。 |

| 4：完整聊天与外面不一致 | 专注模式“和助手聊聊”直接复用普通 Conversation，统一气泡、卡片、Markdown、图片与错误处理；厨房通用控件样式不会污染普通聊天按钮和段落。 |
| 5：计时浮层边缘与排版 | 统一标题、内容、策略栏的内边距与分隔；空状态、列表、新建表单使用相同容器，内容变化后重新计算位置。 |
| 7：步骤大纲与正文分别滚动 | 专注模式使用受限高度的独立滚动列。手机展开大纲限制列表高度；横屏压缩辅助信息，保留正文、完成按钮与输入区。 |
| 8：“下一步”应切换卡片 | 新增 `navigate_cooking_step`，支持 next/previous/current/step。刷新原卡片并更新当前步骤，不推断已完成；保留现有计时策略，首尾和旧版本明确拒绝。 |
