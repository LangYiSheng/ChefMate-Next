# 剩余设置页与专注底栏统一

日期：2026-10-27。版本维持 0.2.1。

## 本轮修正

- 上一轮只有多标签面板去掉了外层大背景，单分组页面仍使用旧卡片。本轮将所有 SettingsGroup 统一为透明、无套壳内边距的分组，保留标题、行列和 32px 组间距。上下文、开发者、数据、记忆与组件采用同一规则。
- 数据状态改为语义列表与轻量连接标签，真实 0 和未报告状态分别表达。
- 日志按版本和分节平铺，按内容容器宽度切换两列/单列；原始发布与后续实现来源折叠保留。关于页收紧品牌区，集中版本、运行方式、构建与真实数字，保留隐私和营养边界。
- 分类切换清除上页提示和错误，异步试听离页后关闭音频并忽略迟到提示；草稿和修订保护不变。
- 专注页统一 canvas，底栏透明，回复、建议与紧凑输入共用阅读轴。移除跨两个样式文件重复的 footer 高度规则；短横屏采用并排回复/输入，完整聊天保留唯一输入节点。

## 验证

- 前端完整回归 32 文件、264 项通过；TypeScript 与生产构建通过；21 个 CSS 文件解析通过。
- 新增覆盖：分类切换提示清理与草稿/原修订保留、试听迟到关闭、0/未知状态、关于 API 真值、日志来源展开和索引，以及回复折叠/完整聊天切换时输入节点与草稿保留。
- 正式设置页逐项验收上下文、开发者、数据状态、版本日志与关于。外层分组实测透明、0px 内边距、0px 边框；预算输入仍保留独立微明度表面。日志在当前宽度实测两列，来源展开明确区分原始 `bd242d9` 与后续实现。关于页读到真实 0.2.1、358 道基础菜谱和 7 个组件。
