# 微明度层次与界面动效验收

日期：2026-10-27。当前版本仍为 0.2.1；本轮不调整版本号。

## 实现

- 聊天、侧栏、详情、设置、菜谱中心、食光手记和厨房组件移除装饰性细描边，用当前主题的微明度表面区分层次。键盘焦点、强制颜色模式及开发者树结构的必要线条继续保留。
- 侧栏选中背景连续滑动，页签和表单选中状态柔和变化；卡片、菜单、弹窗和详情使用小位移与透明度入场。大面板使用无过冲的减速曲线，小按钮、勾选和收藏星标使用轻微弹性。
- 普通聊天与专注回复共用逐字入场：新字符从轻微模糊、透明与下方位置清晰浮现。保留完整字素、链接、列表和代码语义，不修改消息存储内容。
- 长回复最多为尾部 600 个源文本字素建立临时动画节点，延迟均匀分布在 0–420ms，单字动画 360ms，810ms 内清理；历史、刷新和隐藏后返回不重播。减少动态效果立即显示正文，并取消过渡与悬停位移。
- 计时、营养、用量、步骤索引和其他数值显式设置等宽数字，避免 `font` 简写重置继承值。

## 验证

- 完整前端测试：29 个文件，244 项通过。
- TypeScript 与生产构建通过；19 个源 CSS 文件解析通过。
- 浏览器验证首页、食光手记、菜谱列表与详情、设置，以及深浅主题的表面层次。390 × 844 下文档、body 与视口均为 390px；844 × 390 设置页导航、正文与底部操作可见。主表面与卡片实测边框为 0px，营养数字实测为 `lining-nums tabular-nums`。
- 在独立 18766 服务和独立 SQLite 会话中注入确定性答复，验证真实 SSE、前端状态与最终渲染：观测到 63 个动画字符，实际 blur 与透明度均变化，过程文字未进入正文，动画结束后字符节点为 0。刷新历史后动画字符峰值为 0。此项是界面链路验证，不是真实模型效果测试。
- 浏览器检查未记录警告或错误。正式 18765 服务仍 `ready:true`，基础菜谱 358 道，无活动会话。临时页面与预览服务已关闭。
- 实际截图保存在本次可视化目录的 `chefmate-motion-journal.png` 和 `chefmate-motion-mobile.png`。

## 协议边界

当前 `assistant_delta` 同时包含工具前过程文字，不能在到达时认定为最终答复。本轮保留服务端 `result` 确认边界，提供最终正文的逐字入场，不宣称已改成模型网络流的逐字直出。静态 Markdown 不注册动画偏好监听，也不为文本变化额外更新动画状态。

工作区原有 `.gitignore` 和 `test/` 改动不纳入本轮提交。模型、数据库配置、运行数据和构建产物不纳入提交。
