# 额度同步、尾数使用与页面一致性

本轮对应个人资料参考图、七条浏览器批注，以及同级内容字号一致的补充要求。版本号与发布日志保持不变。

## 页面和列表

- 设置与管理平台共用 1280px 正文阅读宽度；标题与正文沿同一条轴线排列。窄屏按可用宽度缩小，各分类不再自行改变整页宽度。模型卡片仍保留适合连接信息的局部宽度。
- 页面切换使用同样的 7px / 380ms 浮入节奏。设置通过动画引用重播，保留已挂载表单草稿；管理列表读取完成后也重播正文，避免网络慢时只看到加载文字的动画。减少动态效果时跳过动画。
- 个人资料采用居中头像首字母、称呼和账号；加入信息改为按浏览器本地日历计算的加入天数。年度 Token 活动复用现有真实用量接口，不生成示例活动或虚构头像。
- 用户统计、用户与额度、用户数据、操作记录共用搜索和分页组件。前三项在已读取的用户列表中筛选、分页；操作记录保留服务端分页与日期、操作者等筛选，不把客户端分页宣称为服务端分页。
- 注册策略默认折叠。收起不卸载草稿，后台刷新期间暂停交互；离开仍使用既有草稿保护与版本校验。
- 账号菜单的额度改为普通单行入口，右侧显示剩余比例。
- 设置、管理和账号菜单共用语义字号：页标题 1.75rem，分区标题与正文 1rem，控件/表格 0.9375rem，辅助说明 0.8125rem。保留资料姓名与统计数字的强调；所有断点的同级内容一致。Select 弹层继承触发按钮的字号与行高，避免 portal 丢失作用域样式。

## 额度准入和展示

旧逻辑在预计调用金额超过可用余额时拒绝请求，使正余额尾数无法使用。现在正余额可以准入最后一次调用，实际预占只取剩余额度，原始完整估算保留在请求记录中。准入仍在数据库事务内完成，其他并发不能重复占用同一份尾数。

模型报告费用后完整结算；最后一次真实费用可能超过余额，超额保留在账本，余额显示归零并停止后续调用。会员、基础、充值的顺序不变，旧窗口归属、退款、核对与重启恢复不变；不会把真实费用截断成剩余余额。

个人百分比只反映已确认消耗。进行中的预占与未报告用量的估算不提前降低比例，而显示处理中或核对中；后台准入与管理员金额视图仍保守计算这些占用。因此核对期间可能保留正比例但暂时不能发起新请求，界面和文档明确区分该状态。

环形数字与额度条首次从零增长，后续变化从当前显示值过渡。成功、失败、取消和断线恢复终态会通知账号刷新；同账号跨标签、回到页面和会员窗口边界也会校准。短暂读取失败有有限重试，不按每个 Token 轮询。
