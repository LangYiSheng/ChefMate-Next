## 实现

- 进度文字按每字 72ms、最长 1800ms 显示；同一状态的 SSE 更新不重启动画，减少动态效果设置直接显示完整文字。主区和右侧工作区使用同一水平位移进出专注模式。
- 共享 Select 取代原生下拉框：键盘选项、输入定位、Escape、外部点击、焦点和 dialog 顶层门户统一处理，菜单按可见空间调整。文本输入框统一主题、边框、焦点和禁用样式。
- 设置使用统一标签页；长页面只在内容区宽度足够时显示页内索引，滚动仅发生在设置内容中。
- 开发者上下文条显示七类估算占比；水印显示模式、版本和实时时间。工具和组件目录分组、搜索并标明真实可用条件；请求与执行轨迹展示实际留存的角色消息、系统提示、调用参数、结果和报告用量，未捕获内容不补造。
- 普通偏好独立服务端存储和 CAS，允许活跃轮次修改。模型工具仅有白名单字段，不能读取或修改模型、开发者、系统或密钥。现有显式组件清单不会擅自追加新组件。
- 对话内草稿读取、修改、请求确认及发布形成完整流程。确认绑定会话、草稿版本、等待问题与真实答案；修改后旧确认失效。审核卡读取当前记录，等待问题期间仅由问题面板确认，加载、续轮和保存期间禁止重复发布。
- 个人菜谱与基础菜谱共用食材、难度、营养契约。数量单位不推测克重；难度须有原文依据，手动选择记录为用户补充；无关编辑保留口味、做法与厨具字段。

## 验证边界

自动检查覆盖控件键盘与生命周期、草稿版本、发布确认、设置保存与并发、运行结束后偏好同步及旧请求返回顺序。真实浏览器使用独立端口 18766、独立 SQLite 与配置副本，正式会话数据不用于写入测试。

真实模型验收使用合成输入，并通过页面、HTTP 与数据库结果共同核对；不是只凭助手回复认定操作成功。窄屏验收使用浏览器视口模拟，不能替代真机、输入法或所有操作系统的辅助技术测试。
