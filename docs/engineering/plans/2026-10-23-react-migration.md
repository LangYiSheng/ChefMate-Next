# React 前端完整迁移

当前任务由用户明确授权：全面迁移，不保留旧前端实现，迁移后自测、提交并启动可体验服务。

## 边界

- 使用 React、TypeScript、Vite，保留 Python 领域服务、HTTP/SSE 合同和用户数据。
- 用 React 组件、外部运行状态与 hooks 替换原生 DOM 控制器；设置进入同一 React 应用，移除 iframe。
- 覆盖聊天、图片、问答/确认、推荐回复、会话管理、工作区、全屏烹饪、计时器、菜谱与食光手记、全部设置与开发者视图。
- 保留既有颜色、字体、图标和响应式视觉资源，删除旧 HTML/JS 入口和绑定旧实现的测试。
- 版本保持 0.2.0，保留已有无关 `.gitignore` 与 `test/` 改动。

## 验收

1. TypeScript 检查、生产构建、适量行为测试与后端回归。
2. 重点验证 SSE 分块/断流恢复、切会话不终止任务、迟到响应隔离、确认幂等、草稿/图片保留、计时提醒生命周期。
3. 隔离数据的真实服务检查：设置、库检索、Agent 往返、任务动作、刷新恢复、桌面/窄屏/横屏、控制台与静态资源。
4. 删除旧实现，检查文档链接、提交与远端一致性，最后启动可体验服务并报告地址与数据状态。
