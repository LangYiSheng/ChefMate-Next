# React 迁移完整性与界面复核

用户要求：全面检查迁移遗漏和旧实现残留，重点验证会话切换、计时器、设置保存；恢复统一的按钮、布局、字体、主题表现，发现问题直接修复并提交。

## 对照与边界

- 以迁移前 `6606b7a` 的已确认交互、现行设计规范和真实 HTTP 合同为依据，历史 UI 仅在隔离运行目录作为浏览器对照，不回引旧运行代码。
- 会话：快速切换、迟到读取、草稿和图片、后台流/轮询、确认续轮、分页与失败重试。
- 厨房：完整备料列表、当前/浏览/完成步骤、专注阅读分页、计时自动展开、时钟校准、后台提醒、声音解锁和 Escape 优先级。
- 设置：真实 revision 合同、保存失败与部分成功、跨分类草稿、未保存导航、主题/字体/估算/密度、记忆与个人中心。
- 界面：清除旧 CSS 结构与 React 结构混搭，使用源码中的统一语义 token、字体角色、控件和响应式布局；检查全部主界面及浅色、深色、系统主题。

## 验收

针对可复现问题增加行为回归；运行 TypeScript、构建、前后端检查、文档链接与差异检查。浏览器对照桌面、窄屏、横屏，验证真实模型/HTTP与数据恢复，提交后更新常用服务并保留原用户数据。
