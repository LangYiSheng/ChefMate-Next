## 使用与维护

| 要做什么 | 入口与边界 |
| --- | --- |
| 注册、设置个人偏好、查看额度，或管理用户与模型 | [账号与管理员操作](accounts.md)；站内额度由管理员发放，不包含支付渠道 |
| 首次启动、升级、备份和恢复 Docker 服务 | [Docker 部署与备份](deployment.md)；账号与个人数据、公共菜谱分别保存在 PostgreSQL，图片与设置使用持久卷 |
| 保留已有 SQLite 个人数据并迁入 PostgreSQL | [显式迁移指南](migrate-sqlite.md)；先备份并核对归属，普通启动不自动认领旧资料 |

## 参与开发

[模块地图与开发指南](development.md)列出源码入口、本机启动、检查命令和隔离验证方式。开始改动前，按涉及的规则查[设计规范](../design/README.md)，实现字段和端点时查[接口参考](../reference/README.md)。

公共菜谱库、在线个人业务库与离线 USDA / 清洗数据职责不同。运行或验证时按对应指南选择连接，避免把测试写入日常用户数据。
