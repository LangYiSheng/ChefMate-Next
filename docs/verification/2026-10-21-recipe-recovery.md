# 个人菜谱删除与恢复验收

2026-10-21。仅操作 18766 隔离预览中新建的专用验收菜谱，未操作正式会话或已有菜谱。

## 实现与边界

- 草稿和已保存菜谱均可移入回收站，恢复后回到原状态；每次变更校验 revision 并递增。
- 正常列表、检索和菜谱详情隐藏回收站内容，收藏随删除移除。
- 正在做的菜和食光手记使用已冻结的菜谱快照，不因删除原菜谱失效。
- 助手先发起真实用户问题，等待用户选择。确认回执绑定会话、问题、菜谱版本及原轮次；用户文字和模型文字不能直接代替已保存答案。
- 保留、取消生成、跨会话、版本变化和旧回执重放均不允许再次删除。

## 真实模型

模型 `gpt-5.6-terra`，使用应用实际配置的模型接口、HTTP/SSE 与 SQLite 状态。

专用菜谱 `custom-6459d36c-acad-4a8d-8ac9-677d2988bf6f`；删除会话 `b7fe8d39-59f0-4a2f-af46-06c050b008db`。

1. 模型检索草稿并调用请求删除工具，出现待回答问题。此时仍为草稿 v1。
2. 用户选择保留；模型调用结清工具，仍为草稿 v1。
3. 再次请求删除，仍先等待用户回答，版本不变。
4. 用户确认删除；模型调用执行工具，变为回收站 v2，正常详情返回 404。
5. HTTP 恢复后为草稿 v3，document 与删除前一致。

首次实测发现模型在“保留”后只用文字回复，未结清回执。已给等待回执增加明确的下一步工具说明，重新完整实测通过。脱敏原始证据保存在本地忽略目录 `.runtime/personal-acceptance/recipe-deletion-live.json`。
