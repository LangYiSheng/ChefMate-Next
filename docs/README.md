# ChefMate 文档

先从用户手里的一顿饭认识系统，再沿着工具、状态和数据往里走。

当前 App 版本为 **0.3.0**。账号、会员额度、管理平台、Docker/PostgreSQL 与本轮交互改进见[0.3.0 发布记录](engineering/records/2026-10-28-release-0.3.0.md)。历史版本及提交来源保留在设置中的“版本更新日志”。
