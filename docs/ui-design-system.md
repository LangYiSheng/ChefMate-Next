# ChefMate 视觉规范

参考 LanCher Code WebUI 的平铺侧栏、圆角主工作区和细边界；保留厨房产品的低饱和绿色。颜色统一定义在 `apps/chefmate-playground/static/colors.css`，聊天、设置、工作流组件与做菜模式共用。

| 变量 | 用途 |
| --- | --- |
| `--color-background` | 页面外框、会话侧栏 |
| `--color-canvas` | 主工作区、设置、预览弹窗 |
| `--color-surface` / `--color-hover` | 输入框、轻量内容、悬停态 |
| `--color-border` / `--color-border-strong` | 细边框、聚焦与拖动边界 |
| `--color-text` / `--color-muted` / `--color-subtle` | 正文、辅助说明、低优先级提示 |
| `--color-accent` / `--color-accent-hover` / `--color-accent-soft` | 主操作、悬停、选中背景 |
| `--color-success` / `--color-warning` / `--color-danger` | 成功、待连接和错误；同时配文字说明 |
| `--color-overlay` / `--color-shadow` | 图片预览遮罩、轻阴影 |

常用布局采用 8、12、16、24、32px 的间距。桌面侧栏与页面底色相接，不设置外层卡片；右侧主工作区留 12px，圆角 18px，正文区域最大约 900px；移动端取消外框留白，正文左右 20px、输入区左右 16px。输入字段在手机保持 16px 字号，避免聚焦放大。交互内容使用平铺布局，长内容由所在主区域滚动。

侧栏宽度 208–360px，默认 248px，提供拖动和键盘操作。桌面折叠为64px图标栏，保留品牌、新对话、食光手记、菜谱中心和底部设置；品牌悬停或键盘聚焦后显示展开图标。760px 以下使用抽屉；折叠偏好不会让手机失去导航入口。设置保留左侧导航并占用右侧主工作区，未保存修改通过页内对话框处理。

新对话与其他空间入口共用平铺按钮。会话先读取20条，接近列表底部时按游标每次追加20条，保留滚动位置；失败显示可重试入口。置顶优先，其余按最后对话活动排序。三点菜单提供重命名、置顶/取消置顶、删除；重命名和删除采用页内模态弹窗，删除执行中的对话仍受后端保护。名称与置顶独立持久化，不改变做菜进度和最后活动时间。

图标使用本地 Lucide SVG sprite，入口是 `static/icons.js`；添加图标时同步白名单、sprite 与许可证来源。品牌采用提供的 Chef Buddy SVG，去掉底板，裁紧主体范围，眼睛和笑容保留透明镂空；通过CSS遮罩跟随主题强调色，浏览器图标同步使用同一矢量。图标按钮提供可访问名称，装饰图标从辅助技术中隐藏。

设置保存反馈集中在页脚右侧，以图标与文字区分读取/保存中、未保存、已同步和失败。成功不再占用内容区提示行；错误保留表单附近的说明。系统组件的功能和依赖提供中文名称，技术标识仍可核对。

消息图片为正方形裁切缩略图，完整图片通过页内模态预览查看；支持 Esc、方向键、按钮导航和键盘焦点恢复。确认按钮使用实色强调，放弃按钮使用轻边框；无须额外重复“尚未确认”。动画尊重系统减少动态效果设置。


全屏模式作为主聊天右侧的另一个主工作区，打开和返回以水平平移切换，保留页面底色；快速切换时取消过期动画，减少动态效果偏好下直接切换。全屏内容按实际可用高度分页，长步骤、说明和回复拆成连续片段，保留完整信息；用上一页、下一页和手势翻阅，不显示滚动条。输入框常驻底部，内容与助手交流以分段入口衔接。交流沿用同一个输入框、图片草稿、停止和重试，不把打开/关闭全屏当作模型运行的开始或结束。等待与工具状态来自实际执行；最终回答、失败与取消均有独立展示。

输入区使用接近底色的浅表面、轻边框与圆形操作按钮；聚焦仅微调边界，不增加厚光圈或投影。

设置与个人厨房共用 `form-controls.js/css`：字段上方显示名称，输入和选择采用轻填充表面；数字在原生输入两侧提供增减，开关保留原生空格操作，密码提供显示切换。必填、未知、禁用和错误状态有明确语义；未知数字保持空白。标题桌面28px、手机25px，页签使用下划线，主要按钮高度至少44px。

菜谱中心与食光手记用平铺列表、细分隔线和独立指标呈现内容，不套多层边框。页头主操作与底部保存区保持稳定。桌面详情从右侧展开，可继续浏览列表；按工作区实际宽度判断空间，不只依据浏览器宽度，窄屏改整页。详情页签切换保留同一份表单；所有导航出口保护未保存修改，保存中锁定字段，延迟响应只属于原页面和原编辑器。整页详情隔离背景、约束键盘焦点，关闭恢复原列表焦点。

烹饪步骤使用平铺宋体正文，不套嵌套卡片；正文约23–30px，与无衬线的控件、数字形成层次。当前步骤、浏览步骤和完成状态用文字区分，主要操作触控高度至少44px。全屏页头合并菜名与完成进度，返回使用有可访问名称的箭头，模式入口保持轻量。大纲仅用于浏览步骤，不提供完成勾选框；完成、回到当前步骤和从此处继续固定在内容区下方，长说明翻页后仍可操作。确认完成后跟随下一步，单纯翻阅不改变进度。进入烹饪后，聊天隐藏过时的条件、选菜和备料入口，保留当前做法与餐单。

计时集中在聊天与全屏右上角的图标和时间入口，点开小浮层管理暂停、继续、结束与分钟/秒输入；步骤内仅保留启动或查看入口。新启动的计时直接呈现在浮层，窄屏和短屏的多计时采用分组翻页。到期持续提示，自动打开提醒但保留输入焦点与草稿；Escape优先关闭浮层，不退出做菜。不代替用户完成步骤。每步只展示一个计时器，默认最多3个运行/暂停计时，可设置单计时器模式及切换实际步骤自动清除（默认关闭）；降低上限保留已有计时。倒数由服务端截止时间计算并校准页面时钟，刷新后恢复；页面关闭期间不承诺闹钟通知。

手机设置分类保留横向触滑和键盘导航，隐藏原生横向滚动条，以两侧渐隐提示尚有分类；选中项自动进入可视范围。

新对话展示18种随机能力模板，按选菜做饭、个人菜谱、饮食记录和了解你分类，每次展示至多三张；图片示例随模型实际图片能力显示。填空保持可编辑，模板按钮只替换输入文字。完成回复后的三条推荐使用轻量短标题排列在输入区上方，点击只填入草稿；与实色强调、保存后自动续轮的确认按钮区分。设置关闭推荐后隐藏当前与历史建议。

公开活动采用持续旋转的加载图标，每项新提示逐字出现；同一步 SSE 更新继续原动画，不重复从头播放。辅助技术读取完整提示，减少动态效果时直接展示全文并停止旋转。

食材准备统一使用备菜清单，保留逐菜的真实食材身份、用量与准备状态；不再重复展示采购入口和另一套勾选。模型按用户明确要求修改条件、代选菜或代勾食材后，展示保存后的真实表单或清单供核对，与用户手动操作使用同一版本边界。

助手提出待答问题时，输入区暂时替换为选项和自填答案。问题、长选项和自填区域按可用高度翻卡，完整文字仍可查看；确认按钮固定在问题卡片底部，选择跨页保留，提交后保存答案并继续处理。会话列表以提示点和“等你回答”文字共同标识待答状态，不能只靠颜色传意。全屏内沿用同一问题组件；短屏减少辅助留白，手机自填字号保持16px。

开发者开关开启后，右侧调试栏提供工具、调用、技能和上下文四个入口。工具列表区分已注册与当前阶段可执行，参数以用途、必填项和约束展开；调用输入与返回、技能目录与实际读取记录分开呈现。上下文按轮次和模型请求浏览，依次展示系统提示、用户输入、助手输出、工具回调及可信任务状态，用角色标记、字段说明和按需展开代替整块JSON。只显示实际留存的脱敏请求，图片保留元数据；旧轮次缺记录时明确说明，不用当前配置重建成历史事实。
